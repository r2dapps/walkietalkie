Tactical User Guide

1. How to Join a Frequency

Type any channel name (e.g., alpha-1) or pick a preset button, then tap Establish Frequency. Share the channel link or QR code with friends to pair instantly.

2. Using Push-To-Talk (PTT)

Press and hold the big red PUSH TO TALK button (or hold the Spacebar on desktop) while speaking. Release when done. You will hear an authentic Roger Beep chime on release.

3. P2P Text Chat & NATO Assist

Tap the 💬 Chat icon to open the channel text log. Use the top NATO quick buttons to send tactical phrases (Alpha, Bravo, Wilco, SOS) instantly without typing.

4. Security PIN Lock

Lock your radio screen anytime using the Hamburger menu or Settings. Default PIN is 0000. Change it anytime in your Operator Profile.
